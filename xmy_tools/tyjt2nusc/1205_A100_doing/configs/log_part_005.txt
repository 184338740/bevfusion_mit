找到配置文件./xmy_tools/tyjt2nusc/1205_A100_doing/configs/tyjt_convfuser_tmp_1205_V8.1.yaml，定位到model.encoders.camera.backbone.window_size，必须改为 8：
yaml
model:
  encoders:
    camera:
      backbone:
        type: SwinTransformer
        window_size: 8  # 唯一关键修改：7→8
        # 其他参数（num_heads等）保持不变
        num_heads: [3, 6, 12, 24]
        embed_dims: 96
        ...
2. 验证配置修改是否生效
修改后，可先执行以下命令检查配置加载结果，确认window_size是否为 8：
bash
运行
python -c "
from mmcv import Config
cfg = Config.fromfile('./xmy_tools/tyjt2nusc/1205_A100_doing/configs/tyjt_convfuser_tmp_1205_V8.1.yaml')
print('window_size =', cfg.model.encoders.camera.backbone.window_size)
"
输出必须是 window_size = 8，否则说明配置文件路径错误 / 修改未保存 / 有缓存。
3. 重新执行训练（带环境变量）
bash
运行
# 先清空可能的缓存（可选）
rm -rf ./runs/v8.1-1210-01/*


# 加载A100适配的环境变量（必须）
export CUBLAS_WORKSPACE_CONFIG=:4096:8
export NVIDIA_TF32_OVERRIDE=0
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True


# 重新执行训练
torchpack dist-run -np 1 python tools/train.py ./xmy_tools/tyjt2nusc/1205_A100_doing/configs/tyjt_convfuser_tmp_1205_V8.1.yaml --run-dir runs/v8.1-1210-01
关键补充说明
为什么 window_size=7 必改？A100 的 Tensor Core 仅支持维度为 8/16/32/64 等 2 的幂次的矩阵乘法（适配 Tensor Core 的 Tensor Op），7×7=49 是奇数，触发底层 CUBLAS 报错；改为 8×8=64 后，完美适配 Tensor Core 的计算规则。
配置修改不生效的常见原因
改了错误的配置文件（比如路径写错，训练加载的是其他 yaml）；
配置文件有多层继承（比如 base 配置覆盖了当前配置的 window_size）；
编辑器未保存修改（比如 vim 编辑后未:wq）。
num_heads 无需修改你的num_heads=[3,6,12,24]满足embed_dims%num_heads=0（核心要求），仅影响训练速度（5-10%），不影响功能，无需改动。
按此步骤修改后，CUBLAS_STATUS_NOT_SUPPORTED报错会彻底解决，训练可正常启动。
