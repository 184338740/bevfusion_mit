核心根因：get_cam_feats 方法的参数计数逻辑理解错误
Python 中方法的 self 算第一个「位置参数」；
调用时 self.get_cam_feats(img, depth, mats_dict) → 实际传了 self(1) + img(2) + depth(3) + mats_dict(4) 共 4 个位置参数；
若方法定义为 def get_cam_feats(self, img, depth=None, mats_dict=None): → 正好接收 4 个参数（self+img+depth+mats_dict）；
你仍报错，说明：① 父类 BaseTransform 的 get_cam_feats 未正确修改；② 子类（如 DepthLSS）的 get_cam_feats 参数不匹配；③ 装饰器干扰参数计数。

@force_fp32()
def get_cam_feats(self, img, depth, mats_dict): 
    # ========== 修复1：参数名映射（img→x，depth→d） ==========
    x = img  # 把输入参数img赋值给原有变量x
    d = depth  # 把输入参数depth赋值给原有变量d
    # ========== 修复2：先赋值x，再获取device（核心！） ==========
    orig_device = x.device  # 此时x已定义，无引用错误
    # =========================================================


    # ========== A100兼容：所有计算转CPU ==========
    # 1. 输入转CPU+FP32
    x = x.cpu().float().contiguous()
    d = d.cpu().float().contiguous()
    
    # 2. 所有层权重临时转CPU（保存原设备，后续还原）
    weight_devices = []  # 保存权重原设备，用于还原
    for module in list(self.dtransform) + list(self.depthnet):
        if hasattr(module, 'weight') and module.weight is not None:
            weight_devices.append((module, 'weight', module.weight.device))
            module.weight = torch.nn.Parameter(module.weight.cpu().float())
        if hasattr(module, 'bias') and module.bias is not None:
            weight_devices.append((module, 'bias', module.bias.device))
            module.bias = torch.nn.Parameter(module.bias.cpu().float())
    # =========================================================


    # 原有业务逻辑（完全不变）
    B, N, C, fH, fW = x.shape
    d = d.view(B * N, *d.shape[2:])
    x = x.view(B * N, C, fH, fW)


    d = self.dtransform(d)
    x = torch.cat([d, x], dim=1)
    x = self.depthnet(x)


    depth_out = x[:, : self.D].softmax(dim=1)
    x = depth_out.unsqueeze(1) * x[:, self.D : (self.D + self.C)].unsqueeze(2)


    x = x.view(B, N, self.C, self.D, fH, fW)
    x = x.permute(0, 1, 3, 4, 5, 2)


    # ========== 关键补充：还原权重到原设备（避免权重永久留在CPU） ==========
    for module, param_name, dev in weight_devices:
        param = getattr(module, param_name)
        setattr(module, param_name, torch.nn.Parameter(param.to(dev)))
    # ========== 结果转回原设备（CUDA） ==========
    x = x.to(orig_device)


    return x
